Model Eval Sample
=================

This sample demonstrates the official-eval publication shape using the signed
official fixture artifact.

Contents:

- `official_signed.eslams`: signed official fixture artifact generated by
  `python3 -m eslams.cli fixtures artifact --kind official-signed`.
- `plan.json`: fixture plan metadata aligned to the source artifact suite
  context.
- `publication_bundle/`: exported `official-proof` bundle for Platform-style
  ingestion.

Validation:

```bash
python3 -m eslams.cli validate --profile official-bundle sample_runs/model_eval_sample/official_signed.eslams
python3 -m eslams.cli publish validate sample_runs/model_eval_sample/publication_bundle --json
```

Notes:

- The fixture is signed with the deterministic fixture key id, so validation
  reports `unverified_missing_key` unless the matching fixture signing key is
  present.
- It contains no provider API receipts because it is generated by the built-in
  deterministic fixture agent.
- It includes the Core 0.2.0 public replay projection, including
  `replay/display_frames.jsonl`, and explicit publication eligibility fields.
