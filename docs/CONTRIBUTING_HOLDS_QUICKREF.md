# Contributor holds quickref

One page for contributors and agents. This complements
[#25](https://github.com/ElectronicSlams/eSlams/pull/25). It does not replace
that page and does not rewrite its body.

## Hard holds

1. Draft pull requests only until founder gates. No merge, no deploy, no DNS.
2. No R2 pull, no D1 delete, no Hugging Face upload. Org `ElectronicSlams` may still 404.
3. Do not rewrite #19–#21 bodies (leaderboard retirement / Wave B HOLD / F1–F6).
4. Core Low F7–F10 code lives only in #26. Do not open a sibling implementation pull request.
5. Local Artifact ≠ Official ≠ Grand Slam.
6. Platform (`makriman/eSlamsPlatform` or equivalent) is a different repository. Core does not ship a Workers deploy from this tree.
