# Community code of conduct

This code applies to project issues, pull requests, reviews and other
project-managed community spaces. Everyone should be able to contribute
without harassment.

Treat others respectfully. Critique claims and code with reproducible evidence,
explain disagreements, and accept corrections. Do not harass, threaten, insult
or discriminate against participants. Do not publish someone else's private
information or credentials. Avoid sexual harassment, spam and disruptive
behavior.

Report conduct concerns privately to hello@eslams.com with relevant links and
context. For vulnerabilities or credential exposure, follow [SECURITY.md](SECURITY.md)
instead of posting sensitive details publicly. Maintainers will review reports
and may remove inappropriate content, request a correction, or restrict
participation. They should handle reports discreetly and explain moderation
decisions to the affected participants when appropriate.

Maintainers and contributors are both expected to follow this code. A report
or disagreement alone is not evidence of misconduct.
